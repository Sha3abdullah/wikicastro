# ويكي كاسترو

قارئ ويكيبيديا مبني على **مسارات القراءة**: تكتب موضوع ("اليوم بقرأ عن الدولة العثمانية")،
والتطبيق يجمع المقالات المرتبطة فيه من ويكيبيديا، وتقرأها وحدة وحدة وتتابع تقدمك.

## المميزات
- **مسار لكل موضوع**: نتائج البحث + مقالات مشابهة للمقالة الأساسية (`morelike`)، وزر لسحب مقالات أكثر.
- **تقدم واضح**: نسبة الإنجاز لكل مسار، ومقالات اليوم، وأيام القراءة المتتالية.
- **قارئ نظيف**: بدون مراجع وقوالب تصفح، بخط نسخ مريح، ووضع ليلي، وحجم خط تقدر تغيّره.
- **الروابط داخل المقالة** تفتح في نفس القارئ، وتقدر تضيف أي مقالة للمسار.
- تُسجَّل المقالة مقروءة بزر «خلصتها»، أو تلقائياً لما توصل آخرها بعد وقت معقول.
- عربي أو إنجليزي لكل مسار.
- **تطبيق قابل للتثبيت (PWA)** على الجوال والكمبيوتر، والمقالات اللي فتحتها تنقرا بدون نت.
- التقدم محفوظ في المتصفح، مع تصدير واستيراد من الإعدادات.

## التشغيل محلياً
ملفات ثابتة بدون أي build:

```sh
npx http-server -p 8080 .
# افتح http://localhost:8080
```
